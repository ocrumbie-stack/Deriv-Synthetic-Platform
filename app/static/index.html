Sizing

Lots and Pips

1 lot = 100,000 units of the first currency in the pair; 0.1 is a mini lot and 0.01 a micro lot. A pip is 0.0001, or 0.01 on yen pairs.

Leverage isn't set per bot: OANDA sets the margin needed for each pair on your account.

Once connected

How Bots Will Trade

Alerts will go to their own forex webhook. Entries are refused outside each pair's trading window on the Overview page; exits always go through.

Stops are placed on OANDA with the order. Until OANDA is connected, bots are saved but nothing trades.

Webhook

TradingView Alerts

Send alerts to /webhook/blofin, in the same format as the Synthetic webhook. Tickers like BTCUSDT or BTCUSDT.P trade BloFin's BTC-USDT perpetual future.

The alert's strategy must match a crypto bot, which sets the margin and leverage. take_profit and stop_loss are prices, held on BloFin.

Demo / live

How It Applies

Crypto follows the demo/live switch: demo trades BloFin's demo-trading account, live trades real money. Each mode has its own BloFin API key, and this page only shows the current mode.

Emergency Stop blocks crypto entries too. Exits always go through. An entry against an open opposite position closes it first; a second entry the same way is refused.
